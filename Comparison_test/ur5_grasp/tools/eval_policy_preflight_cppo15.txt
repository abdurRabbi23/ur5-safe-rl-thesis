Evaluate task success AND safety violations for a frozen policy.

options:
  -h, --help            show this help message and exit
  --num_envs NUM_ENVS   Parallel envs used to collect episodes.
  --task TASK           Name of the task.
  --episodes EPISODES   Completed episodes to score (per eval seed).
  --seed SEED           EVAL seed: fixes the cube spawns. Deliberately
                        disjoint from the training seeds (1/2/3) so a seed
                        number can never be mistaken for a policy pairing.
                        Keep it >= 100.
  --backend {rsl_rl,skrl}
                        Which library wrote the checkpoint. rsl_rl ->
                        model_*.pt, skrl -> agent_*.pt.
  --agent AGENT         Agent config entry point. rsl_rl_cfg_entry_point |
                        rsl_rl_cppo_cfg_entry_point | skrl_cfg_entry_point |
                        ...
  --label LABEL         Short name for this run in the report (e.g. cppo_s1).
  --lift_frac LIFT_FRAC
                        HEADLINE lift rule: cube must reach this fraction of
                        the episode's COMMANDED goal height.
  --min_height MIN_HEIGHT
                        Legacy absolute lift threshold (m, world z), Isaac
                        Lab's own. Reported alongside, not the headline.
  --goal_tol GOAL_TOL   HEADLINE goal-reach bound (m). Default 1 cm.
  --goal_tols_extra GOAL_TOLS_EXTRA
                        Extra goal-reach tolerances (m) reported as context,
                        so a near-miss is distinguishable from a total
                        failure. The headline stays --goal_tol.
  --report REPORT       Report file to APPEND to.
  --csv CSV             Summary CSV (one row per run) to APPEND to.
  --episode_csv EPISODE_CSV
                        Per-episode CSV. Default:
                        ur5_grasp/tools/eval_episodes/<label>_seed<seed>.csv.
                        This is what makes the DISTRIBUTION reconstructable —
                        do not skip it.
